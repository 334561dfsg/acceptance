# 账户安全原型

客户使用账号、密码及 MFA 动态验证码登录。未绑定 MFA 时先校验账号密码，再进入强制绑定页；完成验证器绑定后直接进入账户概览。已绑定用户必须验证当前动态码。登录页不提供返回首页、恢复码、管理后台或忘记密码入口。

账户信息 → 安全设置支持扫码/手动密钥绑定、更换验证器、修改密码。不生成或保存恢复码，不支持恢复码验证，也不提供单独解绑。更换验证器需要当前动态码，新密钥验证成功后替换旧密钥。忘记密码的恢复流程留待总管理后台设计。

绑定后的付款确认、收款账户修改/删除和修改密码需要动态码。修改密码先检查当前密码、新密码规则和两次一致性，再校验 MFA；成功后退出，新密码登录，MFA 保留。

TOTP 使用 SHA1、30秒、六位，允许前后一个时间窗口；拒绝重复验证码，连续五次错误限制一分钟。

## 原型边界

账号 `demo@acceptance.example`，初始密码 `Acceptance@2026`，仅供本地原型。登录、密码与MFA状态仅存在当前页面运行时内存，刷新重置。二维码在本地生成，不上传密钥至第三方服务。密码使用带随机盐的PBKDF2摘要。前端代码及内存不是可信安全边界。

正式环境必须通过自有后端实现账号管理、可信登录、加密密钥存储、密码/TOTP验证、防重放、限流、操作授权及审计。PayFi文档未提供这些认证接口。

## 验证

15项测试通过：TOTP标准向量、错误绑定、绑定结果只公开时间、拒绝非动态码与重复码、取消挑战、失败限流、密码规则及修改后旧密码失效，以及既有资金业务测试。浏览器已确认登录页只保留账号、密码、MFA和登录操作。手机验证器完整绑定后的端到端登录与改密尚未验证。
