# 客户账户管理原型

## 页面

- `/admin/customers`：客户账号、企业、账号状态、企业支付通道、MFA 状态、创建时间；搜索、状态筛选、分页、新增客户。
- `/admin/customers/:id`：客户信息、安全维护、企业资料、收款账户、充值订单、付款订单、客户操作记录。银行及订单支持只读详情。
- `/admin/activity`：管理员、客户账号、操作、时间、原因；搜索与分页。
- `/client/password-setup`：新建或重置密码后的客户必须先设置新密码，再完成 MFA 绑定。

## 行为

- 新建客户的登录邮箱唯一，初始密码符合现有密码强度规则；不记录或展示已保存密码。
- 停用阻止登录和后续受保护路由访问，若当前本地客户会话相同则退出。启用不修改 PayFi 企业支付通道。
- 重置密码使旧密码失效，下一次登录必须修改临时密码；MFA 绑定保留。
- 重置 MFA 清除原绑定，下一次登录须重新绑定；密码保留。
- 账号维护需确认并填写原因，成功写入本地操作记录，不记录密码或 MFA 密钥。
- 客户资料快照与客户系统数据分离；读取另一位客户不切换当前客户会话。
- 企业支付通道、银行审核、交易订单均只读，不模拟管理员代替 PayFi 审批。

## 当前边界

这是前端原型，管理台沿用系统入口直接进入。尚未接入管理员身份认证、服务端权限校验、账号管理后端或真实 PayFi 查询。
账号元数据、密码摘要、MFA、操作记录仅保存在当前标签页 sessionStorage，刷新可恢复，不跨标签页或设备同步。已有业务资料仍沿用客户系统的内存数据和固定样例，不是持久化数据库。
正式上线需将认证、权限、密码重置、会话撤销、客户数据隔离及审计迁至服务端；本地检查不是安全边界。

## 验证

- 构建与 28 项测试通过。
- 回归包含新账号/启停/密码重置、刷新恢复、旧密码拒绝、默认账号凭据保留、管理台数据快照不覆盖客户数据。
- 浏览器查看客户列表、客户详情、充值订单分页、详情弹窗、停用确认与取消后的焦点返回。
- 移动端完整流程、真实后台权限和接口联调未验证。
